Design a complete, modern, enterprise-grade web application UI for a platform called “CoopInsightAI: An Intelligent Cooperative Monitoring and Management System”.

The system is used by cooperative members, managers, government officials, and administrators to monitor, manage, and analyze cooperative performance using AI-driven insights.

-----------------------------------
GLOBAL LAYOUT
-----------------------------------
- Desktop-first design (1440px width)
- Fixed left sidebar navigation (240px width)
- Top navigation bar with system title and user profile
- Main content area with responsive grid layout
- Clean SaaS dashboard style

-----------------------------------
SIDEBAR NAVIGATION
-----------------------------------
Include icons and labels for:
- Dashboard
- Cooperatives
- Members
- Activities
- Financials
- AI Insights
- Government Monitoring
- Reports
- Notifications
- Integrations
- Security & Audit

-----------------------------------
DESIGN STYLE
-----------------------------------
- Modern SaaS admin dashboard
- Primary color: Blue (#2563EB)
- Background: Light gray (#F9FAFB)
- Cards: White with soft shadows
- Rounded corners (medium radius)
- Clean typography with strong hierarchy
- Consistent spacing (8px grid system)
- Use icons throughout the UI
- Professional and minimal design

-----------------------------------
AUTHENTICATION SCREENS
-----------------------------------
Design:
- Login page
- Registration page with role selection:
  (member, manager, government official, admin)
- Fields: name, email, phone, national ID, password
- Password strength indicator
- Email verification UI
- Password reset flow
- Multi-factor authentication setup screen

-----------------------------------

- Charts: performance trends
- Recent activity feed

3. Member Dashboard:
